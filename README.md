# To-do-shark V1

Application de listes Jour, Semaine, Mois et Océan, dérivée de SharkHabits.

- Jour : 3 dents par tâche. Semaine : 10. Mois : 30.
- Plusieurs listes nommées par période, création, modification, suppression et cases à cocher.
- Navigation dans les périodes passées et futures. Une tâche appartient à une période précise et ne se répète pas automatiquement.
- Récompense unique par tâche ; décocher ne retire pas les dents et recocher ne les redonne pas.
- Océan repris du dépôt shark-habits2 : 26 espèces, jusqu’à 5 requins, boutique intégrée et décoration tactile.
- 100 dents, un requin gris et trois décorations de départ. Données locales indépendantes de SharkHabits ; export JSON dans les paramètres. Pas de synchronisation entre appareils.

## GitHub Pages
